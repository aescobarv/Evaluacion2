Script en Python para calcular rutas y geocodificación mediante la API de Graphhopper, optimizado con diálogos en español, métricas con máximo dos decimales, narrativa de viaje paso a paso y opción de salida segura (s o salir).

Instrucciones de Ejecución:

Abre la terminal en la máquina virtual DEVASC y navega a la carpeta del proyecto:

cd ~/labs/devnet-src/school-library

Ejecuta el script con Python 3:

python3 graphhopper_ruta.py

Ingresa el punto de partida y el destino cuando la consola lo solicite (ej. Santiago, Chile y Valparaíso, Chile) para visualizar los resultados.

Escribe s o salir para finalizar la ejecución.
